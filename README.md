# 流星雨许愿 ✦

对着流星许下愿望——一个单文件、零依赖的星空许愿页面。

**线上地址**：https://ts-jj.github.io/meteor-wish/

## 玩法

- **许愿**：底部输入框写下愿望（≥2 字），星尘会把它"写"在夜空里，并引发一场流星雨
- **星图**：多个愿望的落点会自动连成星座图案，愿望足够多时闭合并命名
- **长按召唤**：在夜空任意位置长按 0.4 秒，松手从指尖倾泻一串流星
- **收集祝福**：点住划过眼前的流星可积累"星愿"，满 12 点触发全屏流星暴
- **音乐**：第一个愿望提交后自动播放背景音乐（⋮ 面板可开关）
- **保存星图**：⋮ →「保存星图为图片」，可预览后保存 PNG（iOS 为长按大图存相册）

## 本地使用

单文件应用，把 `index.html` 拖进浏览器即可，无需服务器、无需联网。

## 技术

纯 HTML + Canvas + WebAudio，音乐以 base64 内嵌，全部数据存于 localStorage。
